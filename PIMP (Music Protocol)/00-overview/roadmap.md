# P.I.M.P Roadmap

## Phase 1: Protocol Archive
Goal:
Convert existing P.I.M.P knowledge into a structured local folder that code agents can read.

Deliverables:
- overview docs
- core protocol docs
- rules docs
- schemas
- examples

Success Criteria:
- Codex can read the folder and understand what P.I.M.P is
- the protocol is no longer trapped inside chat history

## Phase 2: Local Engine V1
Goal:
Build a local executable implementation of P.I.M.P.

Target Capabilities:
- accept structured or semi-structured song input
- parse intent into signal stack fields
- validate against formatting and anti-trope rules
- produce lyrics and style prompt
- return JSON and markdown output

Success Criteria:
- repeatable local runs
- modular code structure
- basic tests

## Phase 3: Stabilization
Goal:
Improve output reliability.

Target Work:
- edge case handling
- anti-trope refinement
- style prompt compression improvement
- better formatting validation
- stronger example coverage

Success Criteria:
- fewer generic outputs
- more consistent structure
- cleaner final packages

## Phase 4: Caleb Integration
Goal:
Connect P.I.M.P to Caleb AI as a formal module.

Possible Uses:
- creative intent processing
- lyric generation service
- style prompt compiler
- structured creative export

Success Criteria:
- P.I.M.P functions as a service or callable module inside Caleb

## Phase 5: Evolution Layer
Goal:
Allow controlled growth without corruption of core meaning.

Possible Future Features:
- versioned protocol profiles
- perspective-based creative variants
- genre-specific submodules
- anti-trope scoring
- rewrite suggestions
- safe evolution via MOSES-like validation

## Guiding Rule
The protocol may become more capable over time, but the core meaning of P.I.M.P must remain stable and traceable.
